Step 1

Open Microsoft 365 Copilot

Access Copilot from your Microsoft 365 suite — available via browser, desktop, or Teams.

  • Navigate to microsoft365.com and sign in with your work or school account.
  • Look for the Copilot icon in the left navigation bar or in the app launcher (waffle menu).
  • Alternatively, open Microsoft Teams and find Copilot in the left sidebar.
  • Ensure your account has a Microsoft 365 Copilot license assigned by your IT admin.
⚠ Prerequisite: You need a Microsoft 365 Copilot license to access agent creation. Contact your IT administrator if the feature is not visible.
Step 2

Click "Create Agent"

Navigate to the Agents hub and start creating a new custom agent.

  • In the Copilot interface, look for the "Agents" option in the top navigation or left panel.
  • Click Agents → New Agent from the dropdown menu.
  • Alternatively, click the "Create Agent" button if shown directly on the Copilot home screen.
  • A new agent configuration panel will open — you're ready to start building!
Navigation Path
Copilot → Agents → New Agent
Step 3

Configure Your Agent

Give your agent an identity and clear instructions — this shapes how it behaves in every conversation.

🔛 Name
A clear, friendly name users will recognize.
e.g. "HR Assistant", "IT Helpdesk Bot"
📝 Description
A short summary of what the agent does and who it's for. Shown to users in the agent catalog.
🧠 Instructions / System Prompt
The core behavior definition. Tell the agent its role, tone, and how to respond.
e.g. "You are an HR assistant. Always be professional, empathetic, and reference company policies when answering."
💡 Tip: The system prompt is the most powerful field. Be specific about the agent's persona, scope, boundaries, and response style for the best results.
Step 4

Add Knowledge Sources

Ground your agent in your organization's real data — files, documents, and internal websites (subject to admin permissions).

📂
SharePoint Files
Connect to SharePoint libraries and document repositories across your organization.
☁️
OneDrive Files
Reference personal or shared documents stored in your OneDrive for Business.
🌐
Websites
Add internal or public web pages as a knowledge source for up-to-date information.
  • Click "Add knowledge source" and select your desired source type.
  • Browse or paste the URL/path to the files or sites you want the agent to reference.
⚠ Admin Note: Knowledge source integration may require your Microsoft 365 admin to enable the feature. Check with your IT team if options are greyed out.
Step 5

Save & Use Your Agent

Publish your agent and start using it — or share it with your team.

  • Review all configuration fields — name, description, instructions, and knowledge sources.
  • Click "Save" or "Publish" to make the agent available.
  • Use the "Test" button to validate your agent's responses before sharing.
  • Share your agent with colleagues by copying the agent link or publishing to your org's Copilot catalog.
  • You can edit the agent anytime — update instructions, add new sources, or rename it.
Complete

You're All Set!

Here's a quick recap of the full process to create a Copilot Agent.

1
Open Microsoft 365 Copilot and sign in with your work account.
2
Click Agents → New Agent (or "Create Agent").
3
Set the Name, Description, and Instructions / System Prompt.
4
Add Knowledge Sources: SharePoint, OneDrive, or Websites (if permitted).
5
Save, test, and share your agent with your team.
